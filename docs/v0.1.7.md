# Familiar Desktop v0.1.7

This maintenance patch stops an unfamiliar app's window identity from becoming a network image download inside Omarchy's shared shell.

Foreign Wayland app IDs now go through local icon lookup. URL-shaped, path-shaped and unresolved IDs use a local generic icon instead. Window matching and saved pin identities are preserved. Both primary and fallback image sources reject network URLs, remote file authorities and data URLs.

The Qt 6.12 clipboard correction from v0.1.6 is retained. General, Windows and Mac layouts remain available; personal pins, folders and settings are preserved.

## Update

Update Familiar through Omarchy's plugin update flow. First-time installation remains:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

Complete any setup prompted inside Familiar. Development installations should follow the source-bound rollback instructions in [DEVELOPMENT.md](DEVELOPMENT.md).

## Validation and limits

[PR #96](https://github.com/tcballard/omarchy-plugin-familiar-desktop/pull/96) passed Rust, Node and Qt regression checks on x86_64 and aarch64, plus four disposable desktop smoke configurations, including Qt 6.12 / Quickshell 0.3.2 and official titlebars. These automated checks do not claim physical XPS acceptance or a security audit.

Stable binaries remain Linux x86_64 on the documented Hyprland 0.56.2 ABI. ARM desktop acceptance and marketplace verification remain separate. This patch supports existing Familiar users as the project moves into maintenance; further desktop improvements are intended for upstream Omarchy.
