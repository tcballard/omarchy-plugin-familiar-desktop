# Familiar Desktop v0.1.6

Familiar now works with Omarchy's official titlebar renderer. This release also fixes clipboard handling on Qt 6.12, installation and cleanup edge cases, Chromium app matching and dock drag cleanup.

- Use the official renderer for Mac, Windows and theme controls, including minimise and actions targeting the clicked window. Core keeps ownership of the package and its floating-workspace scope.
- Migrate existing Familiar controls explicitly from Window controls, preserving settings. Moving from the private renderer requires logout/login. Disabling Familiar restores Core's defaults.
- Bound explicit clipboard reads to 16 KiB and two seconds. Editable settings use plain-text TextEdit instead of Qt 6.12's automatic TextInput clipboard reader; failed, oversized or stale paste results are discarded ([marketplace report #10985](https://github.com/omacom/omarchy-plugin-marketplace/issues/10985#issuecomment-6103039773)).
- Fix Show Desktop recovery during updates, stale development receipts after uninstall, symlinked setup/repair paths, and standalone setup/repair on official-package hosts.
- Keep Caps Lock, Command and resize hook markers separate during reset and uninstall.
- Match Chromium PWA profiles exactly, so Profile 1 does not match Profile 10.
- Release dock drag state when a component is destroyed.
- Add source-bound ARM development bundles, first-run setup and rollback, plus native aarch64 portable CI.

General, Windows and Mac layouts remain available. The dock-only direction is deferred to later work.

## Updating

Use Omarchy's plugin update flow, then complete the matching setup inside Familiar. First-time installation remains:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

On official-package hosts, setup keeps Core's renderer. Choose **Use Familiar controls** in Window controls when wanted. Follow the logout/login prompt when migrating from the private renderer. Personal pins, folders and settings are preserved.

Development installations use their source-bound installer and rollback procedure in [DEVELOPMENT.md](DEVELOPMENT.md); keep the snapshot printed by that installer before returning to stable.

## Compatibility and limits

Stable release binaries remain Linux x86_64. ARM has static development artifacts and native CI, but this release does not publish stable ARM binaries or claim ARM desktop acceptance of the combined candidate.

Automated desktop coverage includes Qt 6.11.2 / Quickshell 0.3.1 and Qt 6.12.0 / Quickshell 0.3.2, with the official titlebars v0.2.1 source built against guest headers. It is not verification of every delivered package, device, monitor or scaling combination. Tom accepted PR #92 after desktop testing; detailed environment and scenario results were not supplied in that report.

The official integration uses a guarded adapter to Core's current configuration contract, not a published extension API. Older hosts retain the reviewed private renderer for Hyprland 0.56.2 ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. Removing that fallback remains separate work under [#74](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/74).

CLI application attribution to shared terminal windows remains unresolved; only the independent drag cleanup from #91 is included. Marketplace verification is separate from release publication.
