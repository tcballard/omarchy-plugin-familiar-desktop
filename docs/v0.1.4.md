# Familiar Desktop v0.1.4

Release notes prepared for review. This build is not yet accepted or published.

Windows mode uses one full-width bottom taskbar: 48px tall at the default font scale, with 32px app icons and a labelled Familiar settings button. It now works when Familiar was enabled only as a service or placed in Plugin Drawer. General and Mac restore the previous bar arrangement and height while retaining personal widgets and settings.

- Fix the widget load error on newer Omarchy shells caused by an unsupported button property.
- Keep Familiar's hidden Plugin Drawer copy out of the bar's click routing so the visible settings button and neighbouring bar widgets receive their own clicks.
- Fix Mac dock hover previews and clicks after the dock slides into view by keeping its clickable area aligned with the visible card.
- Enable window actions when opening an app menu or switching between apps without requiring a window-row click; retain explicit selections across refreshes and recover when the selected window closes.
- Preserve Familiar’s service/bar placement through development installation and rollback, including later personal moves and inline settings.
- Place Familiar immediately to the right of Agents on fresh installs, including the candidate installer; updates and repairs preserve an existing placement.
- Address the initial-install 404 reported in [#79](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/79): release automation uploads and checks the verified binaries before publishing, then tests the exact public onboarding URLs and their committed checksums. Failed downloads show the URL and release page inside setup.
- Cover both original and current shell APIs in disposable desktop smoke tests.

## Installation and compatibility

After publication, add Familiar with:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

Finish setup inside Familiar. Existing failed installations must update their plugin source to this release before retrying; an old v0.1.3 checkout still requests v0.1.3 assets. The existing v0.1.3 tag is unchanged.

Supported: Linux x86_64, Omarchy Quattro and Hyprland 0.56.2 ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. The official-titlebar-package guard remains in place. Official-package migration (#74), Qt 6.12 palette compatibility (#78), and the reported input shortcuts/gestures issue (#76) are not included in this hotfix.

Personal pins, settings and rollback snapshots are retained. Review [the release checklist](RELEASE-CHECKLIST.md) and [smoke-test handoff](HOTFIX-SMOKE.md) for exact build identity, acceptance and rollback. Public-download success can only be confirmed after authorized publication; development CI is not a claim that the public 404 has already been repaired.
