# Familiar Desktop v0.1.3

Prepared privacy fix; not yet published or live-tested.

Browser notification text could appear in the local process list when Familiar
saved dock badges. Thanks to HANCORE-linux for reporting it.

Badge data now travels through stdin. Familiar no longer derives badge identities
from notification summaries or missing-app-ID window titles. Browser notifications
still badge the browser; web-app names are no longer guessed from message text.
Saved state retains atomic private-file writes, and malformed or oversized input
leaves the previous state intact.

The QML and rebuilt backend must ship together. v0.1.2 remains affected; its
historical assets have not been changed. Existing private badge keys are retained,
but no longer enter process arguments. Same-user processes and root remain outside
this privacy boundary. Marketplace re-review and live Quickshell verification
remain pending. See [release evidence](RELEASE-0.1.3.md).
