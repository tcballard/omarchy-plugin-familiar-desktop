# Familiar Desktop v0.1.2

Install Familiar once, then finish setup inside Familiar.

- Native `omarchy plugin add` opens first-run setup with Windows or Mac controls.
- Backend and window-control downloads show progress, errors and retry in the same screen.
- Verified existing installs skip onboarding; setup and repair remain available in Windows settings.
- Source-pinned binary checks and interruption recovery remain in place.

## Install

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

Click **Set up Familiar**. No second terminal command is needed. Setup requires curl, jq, coreutils, Linux x86_64 and the supported Hyprland ABI. It reports missing tools and incompatible desktops without opening a terminal or installing system packages.

## Acceptance and compatibility

Tom tested v0.1.1-rc.4 (`812f7a7a878be8f7b71c6f49feb52357cd1d7421`) on the XPS and approved release on 6 October 2026. v0.1.2 changes version metadata, binary pins and release documentation; runtime behaviour is unchanged from that candidate. The version bump rebuilds the backend, with its new digest committed and checked before publication. This is not a claim of exhaustive lifecycle, mixed-scaling or multi-monitor testing, or marketplace approval.

Supported target: Linux x86_64, Omarchy Quattro, Hyprland 0.56.2 commit `efb50993780079460b0cbed1363e2166a2de1d9f`, ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. Other ABIs are refused.

## Remove

```bash
bash ~/.config/omarchy/plugins/io.github.tcballard.familiar-desktop/uninstall.sh
```

Removal restores tracked windows and removes owned configuration, retaining personal settings and backups. Settings navigation/scrolling remains a follow-up in #28. Existing releases and tags are unchanged.
