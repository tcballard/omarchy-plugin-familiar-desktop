# Familiar v0.1.0

Release-note draft for 5 October 2026. Not published; complete the release checklist before using this copy.

Familiar gives Omarchy a few familiar places to click: a dock, visible window controls and settings you can open from the bar.

- **Find the right window.** Open an app, choose one of its windows by name, bring it to your workspace or arrange it on screen.
- **Make room, then get back to work.** Show Desktop hides eligible windows; Restore brings them back. A recovery journal keeps track across shell reloads.
- **Choose what feels comfortable.** General, Windows and Mac starting layouts share your pins. Dock and title-bar sizing can be adjusted independently.
- **Keep the everyday controls close.** Centred settings, active keyboard-shortcut help, optional Home/Downloads/Bin shortcuts, and separate Quit and confirmed Force Quit actions.
- **Let Caps Lock mean Caps Lock.** Choose Normal Caps Lock, Compose or Use configuration. Nothing changes until you choose; unrelated keyboard options are preserved.

Installation uses prebuilt Linux x86_64 components. No Cargo, Clippy, Hyprpm or Hyprland source build on your machine. Window controls require the exact Hyprland ABI listed in the README; unsupported versions stop before configuration changes.

This release focuses on the desktop. The curated Open/Install app collection is planned for v0.2.0, after individual package checks. Paint, Notepad and Task Manager remain separate projects; installed applications continue to work through the dock.

Before removal or downgrade, restore hidden windows and reset the Caps Lock preference. Settings and pins are retained. See the README for installation and the XPS guide for recovery.
