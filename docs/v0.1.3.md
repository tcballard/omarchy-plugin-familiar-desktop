# Familiar Desktop v0.1.3

Windows now uses one full-width bottom taskbar, combining Familiar apps with Omarchy’s native widgets. Switching to General or Mac restores the previous bar layout.

- Choose dock background opacity independently of the header: Follow theme, 0%, 25%, 50%, 75% or 100%. Icons and text retain their opacity.
- Activate the last-used surviving window and correctly reduce title badges as counts fall.
- Place Familiar before Agents on first setup, preserving existing layouts.
- Test development builds with matching source/binaries, checksum verification and rollback, backed by desktop smoke CI.
- Guard titlebar ownership and pause Familiar’s bundled controls when the official Omarchy titlebar package is present. Full migration remains #74, planned for v0.1.4.

## Install

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

Setup and repair remain inside Familiar. Windows mode uses the native bar’s appearance and widget layout; dock-only opacity and additional floating-dock widgets do not transfer to the taskbar.

## Remove

```bash
bash ~/.config/omarchy/plugins/io.github.tcballard.familiar-desktop/uninstall.sh
```

Removal restores owned bar placement and tracked windows, removes owned configuration, and retains personal settings and backups.
