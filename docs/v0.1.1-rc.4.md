# Familiar v0.1.1-rc.4

Familiar now includes first-run setup inside the plugin. Choose a Windows or Mac layout and follow installation progress without opening another terminal.

## Changes

- Install the backend and window controls through Familiar, with failure details and retry.
- Keep the dock hidden until setup succeeds; verified existing installs skip onboarding.
- Verify downloaded binaries against digests recorded in source.
- Coordinate setup with a shared controller, filesystem lock and incomplete marker for duplicate clicks and interrupted installation.
- Reopen setup from Windows settings.

## Validation and scope

PR #30 passed Portable checks and Release binaries on main at `1ff730ad1a706d5a50f18e4c8091666e04ce3864`. Publication additionally requires green checks for the exact tagged source, verifies artifact manifests and checksums, and downloads the uploaded bundle again before publishing.

This is an x86_64 Linux test candidate. Fresh native installation and the complete first-run flow on the XPS still require live acceptance. Automated checks do not establish live desktop acceptance or constitute a security audit.

The manifest/backend version remains 0.1.1; the candidate tag is v0.1.1-rc.4. This candidate does not replace the existing stable v0.1.1 release.
