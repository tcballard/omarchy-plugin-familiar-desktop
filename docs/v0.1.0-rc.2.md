# Familiar v0.1.0-rc.2

Caps Lock can mean Caps Lock. Familiar settings now offer Normal Caps Lock, Compose key and Use configuration. Your keyboard stays as it is until you choose.

The preference preserves AltGr and unrelated keyboard options, never rewrites input.lua, and can be removed through the same settings. Backups and failed-reload recovery protect the main Hyprland config. Per-device overrides still apply; Caps-based shortcuts are replaced while active.

This is a test candidate. Install the matching prebuilt bundle from this candidate’s successful Release binaries workflow using `bash install-candidate.sh windows` (or `mac`). Do not mix an rc.1 backend with this UI. No Rust/compiler installation is required.

Live XPS keyboard, window, focus, monitor and lifecycle acceptance remains outstanding. Follow XPS-TEST.md, and reset the Caps preference and restore hidden windows before downgrade/removal. No published v0.1.0 release is implied.
