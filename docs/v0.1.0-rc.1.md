# Familiar v0.1.0-rc.1

Familiar's next desktop build is ready for its XPS test run once the candidate checks pass.

- **Find your feet.** Getting Started shows shortcuts from your running desktop and opens installed companion tools.
- **Get to the desktop.** Show Desktop puts visible windows away. Restore brings them back, with a recovery journal if an operation is interrupted.
- **Make it easier to click.** Larger dock icons, title bars and buttons, with your choices remembered.
- **Choose how an app closes.** Close one window, request a normal quit for the app's process, or confirm Force Quit when it has stopped cooperating.

The bundle carries prebuilt components and an installer pinned to its exact source commit. No development toolchain is needed on the XPS.

This is a test candidate. Actual Hyprland movement, focus, display changes, scaling and install/update/removal still need the on-device checks. Familiar Paint is separate.

Start with [the XPS checklist](XPS-TEST.md). Tell me which step fails, what you expected, and what happened instead.
