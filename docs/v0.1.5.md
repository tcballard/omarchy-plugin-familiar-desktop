# Familiar Desktop v0.1.5

Pending publication: prepared on `v0.1.5` in [PR #81](https://github.com/tcballard/omarchy-plugin-familiar-desktop/pull/81). Merge and release authorization remain separate from release preparation.

Familiar now recognises registered plugin panels that share Quickshell's application ID. RSS Feed uses its RSS glyph, and recognised panels keep their own identities, windows and pins. The same icon rendering is used in the dock, Windows taskbar and app folders.

- Fix Home and Downloads shortcuts killing ordinary file-manager handlers after an eight-second timeout ([#82](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/82)).
- Fix generated trackpad gestures and Command editing shortcuts on the supported Hyprland Lua API; send balanced key-down/key-up events ([#76](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/76)).
- Qualify Omarchy palette references and signal subscriptions for Qt 6.12, with matching Quickshell and patched Core coverage ([#78](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/78)).
- Give the Home shortcut the matching home-outline glyph ([#83](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/83)).
- Skip the extra Chrome/Chromium titlebar by default; a saved setting lets users opt back in ([#67](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/67)).
- Give settings, app identity, window history, drag interactions, visibility and appearance explicit owners; share repeated app/widget and preference components.
- Refresh the marketplace preview and replace the old prototype code map with the current architecture and validation commands.

General, Windows and Mac layouts remain available. The proposed Mac-only direction and further splitting of the largest components are deferred.

## Updating

Personal pins, app folders, settings and rollback snapshots are preserved. If Command editing shortcuts or Familiar gestures were already enabled on an older installation, reset and reapply those preferences in Familiar to regenerate their managed Lua. Exact older generated files can be replaced safely; personal edits remain protected.

The native installation command remains:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-familiar-desktop --enable
```

Finish first-time setup inside Familiar. Development testing uses the exact source/binary bundle and rollback procedure in [DEVELOPMENT.md](DEVELOPMENT.md); versioned onboarding URLs become available only after publication.

## Compatibility and limits

Supported target: Linux x86_64, Omarchy Quattro and Hyprland 0.56.2 ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. ARM64 and other Hyprland ABIs are not covered by this release's binary evidence.

Automated desktop tests cover Qt 6.11.2 / Quickshell 0.3.1 and Qt 6.12.0 / Quickshell 0.3.2 against pinned Core revisions. Familiar's palette fix does not repair an unpatched Core or a mismatched Qt/Quickshell installation.

Panel discovery uses enabled bar-widget registrations and exact registered names/window titles. Ambiguous, unregistered or differently titled panels keep the existing fallback; a panel must expose a managed window to appear in the dock. The RSS smoke fixture tests panel identity and interaction without feed data or network access.

Full migration to Omarchy's official titlebar package ([#74](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/74)) remains open. The existing guard pauses Familiar's bundled titlebars when that package is present. Broader physical monitor, scaling and app coverage remains open; test and promotion evidence is recorded in [RELEASE-0.1.5.md](RELEASE-0.1.5.md).
